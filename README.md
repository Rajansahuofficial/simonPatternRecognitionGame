# Simon Pattern Recognition Game

A browser-based memory game inspired by Simon. Watch the colored buttons flash, then repeat the sequence by clicking them in the same order. Each level adds another color to the sequence.

## How to play

1. Open `index.html` in a web browser.
2. Press any key to start.
3. Watch the button that flashes, then click the buttons in the sequence shown.
4. Keep going as the sequence grows. Clicking the wrong button ends the game.
5. Reach level 10 to win. After a win or game over, press any key to start again.

## Project files

- `index.html` — game page and buttons
- `style.css` — layout and button styles
- `apps.js` — game sequence, input, and scoring logic
- `mouse click sound.mp3`, `winning sound.mp3`, `mistake wrong tone.mp3` — game sound effects

No installation or build step is required; the game runs directly in the browser.
